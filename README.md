## Getting Started

### 1. Clone the repository
`git clone https://github.com/ahmud-z/bytespace-website`

### 2. Navigate to the project folder
`cd bytespace-website`

### 3. Install dependency
`npm install`

### 4. Run the frontend development server:
`npm run dev`
